This repo contains data on UK and US fuel prices since 2003 as well as code for a dashboard so that the data can be interacted with and explored.
This was made for my Data 350 class project 2.
The dashboard link can be found in the file called "Deployment_Link", when this link is pasted into a browser it will take you to the dashboard. From there you can explore the data.
